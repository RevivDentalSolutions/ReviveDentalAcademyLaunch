Codex Design Rules

The images inside `design-system/references` are the approved Revive Academy visual language.

Do not use reference images as slide backgrounds. Recreate them using editable React, CSS, and Remotion components.

Match the reference images by component behavior: colors, spacing, typography, borders, glow effects, hexagon accents, and proportions.

Preserve all existing Video Lesson Builder export, upload, intro/outro, draft, and lesson attachment behavior.
